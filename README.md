One line of weather forecast (100 characters) for the invented city Tatterwick, written to charm a bored commuter on the way to work. Built by an AI agent for make.fun's "Charm the Commuter: Forecast a City That Isn't" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

Writes the single forecast line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
